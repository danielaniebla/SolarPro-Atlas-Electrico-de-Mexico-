# SolarPro | Atlas Eléctrico de México

**Entrega final** del proyecto educativo TE1020 — Análisis de Circuitos Eléctricos.

## Publicación en GitHub Pages

1. Extrae este archivo ZIP.
2. Sube **el contenido de la carpeta**, no la carpeta contenedora ni el ZIP, a la raíz del repositorio.
3. En Settings → Pages, configura Deploy from a branch → `main` → `/(root)`.
4. Abre la dirección HTTPS proporcionada por GitHub Pages.

El archivo `index.html` depende de `styles.css`, los scripts y las carpetas `assets/`, `datos/` y `fuentes/`. **No publiques únicamente `index.html`**: la página completa necesita los demás archivos.

## Alcance

Los datos documentales, advertencias de fuente, gráficos, recursos audiovisuales y simuladores se conservan respecto de SolarPro 12.1. Las modificaciones de esta entrega se centran en la presentación editorial, los metadatos del sitio y el ícono de la pestaña.
